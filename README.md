# Master Teacher Lesson Planner — Read-Only Demo

This repository contains the **public sample-data preview** for the Master Teacher Lesson Planner.

- Explore the lesson-planning interface with sample records.
- The preview cannot add, edit, delete, import or save customer data.
- The full editable product is **not** included in this public repository.

**Buy the full planner:** https://www.etsy.com/listing/4617189463/lesson-planner-teacher-planner

## Deploy
Import this GitHub repository into [Vercel](https://vercel.com/new). Use Framework Preset **Other**, root directory `./`, and no build command. The root `index.html` is served as a static website.
